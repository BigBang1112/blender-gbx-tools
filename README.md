# Blender Gbx Tools

Blender plugin made for any form of 3D works with la GameBox.

## Build

To use the project in development mode:

1. Install .NET 10 SDK
2. Run `dotnet build` in the root folder of the project (or optionally in the `BlenderGbxTools` folder)
3. Open the plugin in the `BlenderPlugin` folder - VSCode Blender extension is recommended, then run `Blender: Start` within the folder where the `__init__.py` is located
